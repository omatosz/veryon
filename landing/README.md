# Landing page do Veryon

Landing page de portfólio do projeto [Veryon](../README.md), estática, publicada via GitHub Pages. React + TypeScript + Vite + Tailwind + shadcn/ui + Motion.

```bash
npm install
npm run dev
```

Build de produção:

```bash
npm run build
```

O deploy é automático (GitHub Actions) a cada push em `landing/` na branch `main`.
